STARS — Server Provisioning Request

Internal marketing-analytics web tool · lightweight Python (Streamlit) app · hosted on Ubuntu Linux

1 · Machine & specs

Operating systemUbuntu 22.04 LTS or 24.04 LTS (VM or physical). Can share a box with spare capacity.
CPU2 vCPU
RAM4 GB available to the app
Disk~15 GB total (Ubuntu + app + Python deps; ~8 GB is the app itself). No database server needed.

2 · Software (installed via apt during setup)

  • python3-venv, python3-pip — Python 3.10+ runtime
  • git — to pull the code
  • nginx + certbot — reverse proxy & free HTTPS certificate
  • (runs as a systemd service — no extra software)

3 · Network / firewall

InboundOpen TCP 443 (HTTPS) and 80 (for the Let's Encrypt cert). Internal-only alternative: TCP 8501.
Inbound (deploy)TCP 22 (SSH) — can be restricted to GitHub Actions / our IPs.
Outbound (required)Allow outbound HTTPS (443) to the internet — specifically:
generativelanguage.googleapis.com
analyticsdata.googleapis.com
api.github.com
⚠ Most important: the app makes outbound calls to the three domains above. If the server's firewall blocks outbound internet by default, the app installs fine but will not function. Please confirm outbound HTTPS to those hosts is permitted.

4 · Access & domain

Login accessA sudo-capable SSH account (or root) for initial setup. We'll also add a dedicated stars service user + an SSH key for automated deploys.
Domain (recommended)A subdomain such as stars.orientbell.com with a DNS A-record pointing to this server's IP, so the tool has a clean HTTPS URL. Internal-only http://SERVER-IP:8501 is also fine.

5 · Please send back

  • Server IP / hostname
  • SSH username + how to authenticate (we can supply a public key)
  • Confirmation that inbound 80/443 (or 8501) and outbound 443 to the three domains are open
  • The subdomain, once created (if applicable)

What it does NOT need

  • No database server
  • No inbound access to internal systems
  • No GPU / heavy compute (AI runs on Google's cloud, off-server)

Data & security

  • App data (small text files) syncs to our private GitHub repo
  • API keys stored in a local, chmod 600 config file only
  • Access protected by a shared team password
  • Runs as an unprivileged stars user, not root
